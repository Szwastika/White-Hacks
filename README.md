This is a full-stack healthcare assistant tool that helps users:

- Enter symptoms through a web interface
- Receive a basic symptom evaluation
- Search for hospitals based on symptoms or location
- Access streamlined healthcare recommendations

The focus of this project is on core engineering principles:
-Backend routing with Python
-Frontend UI for user interaction
-Database integration for storing and retrieving health data
Key Features
- Symptom Input Page
Users can enter medical symptoms via a web form.
- Hospital Finder
Based on input, the system displays relevant hospital choices.
- Integrated UI
Multiple HTML templates for navigation between symptom entry and results pages.
Project Scope & Metrics
 - Handles symptom analysis input from users
 - Supports lookup and display of hospital options
 - Processes user interactions across 3+ pages
 - Enables local data persistence via SQLite database
